Что это значит
для организации

Общей программы «для пилотов» не существует: каждая привязана к конкретному типу воздушного судна.

Для реализации этих программ образовательной лицензии, как правило, недостаточно: требуется статус авиационного учебного центра и материальная база с тренажёрами.

Программы предполагают тренажёрную подготовку по конкретному типу судна. Без доступа к тренажёру программа нереализуема.

Программ для членов экипажей морских судов и работников железнодорожного транспорта в перечне типовых программ нет — эти темы регулируются иначе.

Что проверить
перед подачей

  1. Определить, есть ли у организации статус авиационного учебного центра.
  2. Установить типы воздушных судов, по которым планируется подготовка.
  3. Проверить доступ к тренажёру соответствующего типа.
  4. Проверить наличие инструкторского состава с действующими свидетельствами.
  5. Убедиться, что речь именно об авиации, а не о водном или железнодорожном транспорте.

Частые ошибки

Планируют «обучение пилотов» без привязки к типу воздушного судна.

Рассчитывают обойтись образовательной лицензией без статуса авиационного учебного центра.

Начинают лицензирование без доступа к тренажёру нужного типа.

Ищут в этом разделе программы для моряков или железнодорожников — их здесь нет.

Формулировка области для реестра лицензий

Подготовка авиационного персонала гражданской авиации

Требования к организациям, готовящим авиационный персонал, устанавливаются не только образовательным законодательством. Формулировку и состав необходимых разрешений необходимо сверить с юристом.

Вопросы

Есть ли общая программа для пилотов?

Нет. Программы привязаны к конкретным типам воздушных судов.

Достаточно ли образовательной лицензии?

Как правило нет. Для подготовки авиационного персонала обычно требуется также статус авиационного учебного центра и соответствующая материальная база.

Можно ли обучать дистанционно?

Нет. Программы предполагают тренажёрную подготовку по конкретному типу воздушного судна.

А программы для моряков и железнодорожников?

В перечне типовых программ их нет. Эти темы регулируются отдельно.

Какие требования к инструкторам?

Инструкторский состав с действующими свидетельствами. Требования устанавливаются не только образовательным законодательством.
