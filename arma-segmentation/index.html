★База кейсов — подбор для звонка

Ищите по названию, сфере или городу — и называйте клиенту конкретный проект со ссылкой. Кейсы с плашкой срока — самые сильные для дожима по скорости.

Цены — из действующих КП (июль 2026). Кейсы — из таблицы кейсов; региональные риски — из «Карты региональных рисков» (актуальность карты ведёт руководитель исполнения). Калькулятор рекомендует, решение принимает менеджер. Минимальный пакет — строго по регламенту.
